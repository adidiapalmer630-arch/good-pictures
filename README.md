# Good Pictures

A simple website for viewing a collection of pictures.

## About

This project shows pictures on a web page. It is built with HTML, CSS and JavaScript.

## Files

- index.html - the main page
- styles.css - the colors and layout
- script.js - the code that makes the page work

## How to View the Website

Open the file index.html in your web browser.

If GitHub Pages is turned on, you can also visit:
https://adidiapalmer630-arch.github.io/good-pictures/
